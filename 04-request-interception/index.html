4.1 请求拦截：匹配规则与读取请求 ​

本章解决两个问题：让 handler 精确命中目标请求，以及从请求里取出路径参数、查询串、请求头、Cookie 和表单。

路径匹配 ​

三种 predicate ​

ts
// 1) 字符串（精确路径，可用通配源 *）
http.get("*/api/users", listUsers);

// 2) 路径模板（Path-to-RegExp 风格，:param 命名参数）
http.get("*/api/users/:userId", getUser);
http.get("*/api/users/:userId/posts/:postId", getPost);

// 3) 正则（应对动态性最强的场景）
http.get(/\/api\/users\/\w+\/avatar$/, getAvatar);

// 通配 *：匹配任意层级
http.get("*/api/files/*", anyFile);

源（origin）部分：

  • * 匹配任意源，浏览器与 Node 通用，本教程一律推荐；
  • 写死 https://api.example.com/users 可严格限定源；
  • 相对路径 /users 只在浏览器有效（Node 无当前 origin）。

匹配只针对路径与源，查询参数（?q=...）不参与匹配 —— 查询串在 resolver 里解析。

FormData 提交 ​

本教程的上传 handler 只认字段名 file，缺字段返回 422：

ts
http.post("*/api/upload", async ({ request }) => {
  const form = await request.formData();
  const file = form.get("file");
  if (!(file instanceof File)) {
    return HttpResponse.json(
      { error: { code: "MISSING_FILE", message: "multipart 字段 file 必填" } },
      { status: 422 },
    );
  }
  return HttpResponse.json(
    { id: crypto.randomUUID(), filename: file.name, mediaType: file.type, size: file.size },
    { status: 201 },
  );
});

请求头校验 ​

ts
http.get("*/api/require-header", ({ request }) => {
  const requestId = request.headers.get("x-request-id");
  if (!requestId) {
    return HttpResponse.json(
      { error: { code: "REQUEST_ID_REQUIRED" } },
      { status: 400 },
    );
  }
  const accept = request.headers.get("accept") ?? "";
  if (!accept.includes("application/json") && !accept.includes("*/*")) {
    return HttpResponse.json(
      { error: { code: "NOT_ACCEPTABLE" } },
      { status: 406 },
    );
  }
  return HttpResponse.json({ echoed: requestId });
});

CORS 模拟 ​

应用与 API 不同源时，MSW 同样运行在应用页面的 worker 中 —— 请求"看起来"跨域，但响应由同源 worker 合成，浏览器不会发起真实预检。 如需模拟跨域响应头，直接在 HttpResponse 上加：

ts
HttpResponse.json(data, {
  headers: {
    "Access-Control-Allow-Origin": "https://app.example.com",
    "Access-Control-Allow-Credentials": "true",
  },
});

passthrough：部分放行 ​

真实接口已就绪、只想 mock 个别端点时，让其余请求穿透：

ts
import { http, passthrough } from "msw";

export const handlers = [
  http.get("*/api/users/*", () => passthrough()), // 用户接口走真实后端
  http.get("*/api/posts", mockPosts),             // 文章继续 mock
