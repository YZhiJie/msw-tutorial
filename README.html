@msw-tutorial/docs ​

基于 VitePress 1.6 的 MSW 3 交互式教程文档站。12 章结构化内容 + 工程化附录，页内可直接编辑并真实发请求的交互实验室。

本地运行 ​

bash
pnpm docs:dev       # 开发 http://localhost:5175（固定端口）
pnpm docs:build     # 构建（SSG）→ docs/.vitepress/dist
pnpm docs:preview   # 预览构建产物 http://localhost:4175

交互组件（在 Markdown 中直接使用） ​

在 .vitepress/theme/index.ts 全局注册，页面里写标签即可：

  • <ApiConsole /> 可编辑方法/路径/请求头/请求体，真实 fetch 并展示状态码、耗时与格式化 JSON
  • <ScenarioLab /> 读写 /api/scenario，滑块调延迟、下拉切错误模式，并可探测 /api/slow、/api/users
  • <GqlConsole /> 4 个 GraphQL 预设（ListUsers/User/CreateUser/DeleteUser），可选 Bearer token
  • <WsDemo /> 连接 /ws/chat，按钮触发 ping / close-me / error-me / disconnect
  • <MockBadge /> 章节角标
  • <ApiContractTable /> 从 API_ENDPOINTS 自动渲染接口契约清单（方法/路径/鉴权/幂等）

页面内真正的 worker 由 .vitepress/mock.ts 懒加载启动（import('@msw-tutorial/mocks/browser')）。

关键技术点 ​

  • SSG 下拦截 msw：msw 的 ./browser 导出声明 "node": null，Rollup 在构建期会因死代码消除解析它。 本项目用两道配合解决（见 .vitepress/config.ts 内联 ssrMswBrowserStub() 插件 + .vitepress/mock.ts 的 import.meta.env.SSR 短路）。
  • 语法高亮：TypeScript/JavaScript，github-light/dark 双主题，行号开启；
  • 本地搜索、中文界面、响应式适配桌面与移动端。

public/snippets/ 提供七个可下载的示例文件：basic-handlers.ts、main-bootstrap.ts、vitest-setup.ts（第二章起步三件套）， 以及按章节抽取的 worker-server.ts（第三章）、request-reading.ts（第四章）、response-shapes.ts（第五章）、graphql-ws.ts（第七章） （作为独立示例使用，模块解析告警属预期）。
