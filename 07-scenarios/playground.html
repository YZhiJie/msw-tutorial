… 正在启动 Mock Worker

本页所有组件都由当前文档站注册的 同一个 Mock Worker 驱动，handler 与 React/Vue 示例、Vitest 测试完全共享（@msw-tutorial/mocks）。刷新页面状态不丢（假数据库持久化在 localStorage）。

全局场景：延迟 / 错误注入 / 鉴权开关 ​

先在这里调好全局参数，下面三个实验室都会受到影响。比如延迟拖到 2000ms 后再发 GraphQL 请求，可以直观看到耗时。

HTTP 实验室 ​

方法、路径、请求头、请求体全部可编辑。几个推荐尝试：

  • GET /api/posts?page=1&pageSize=3&tag=msw
  • GET /api/status/503 与 GET /api/status/429
  • GET /api/slow（配合上面的延迟滑块）
  • GET /api/network-failure（fetch reject，对比状态码错误）
  • POST /api/auth/login 登录（admin/admin1234）后把 token 用在下一个控制台
