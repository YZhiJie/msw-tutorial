8.3 一键切换 Mock / 真实后端 ​

目标：业务代码不动，只改环境配置。本项目用两份 .env 文件表达两种运行模式。

两条启动命令 ​

React 示例：

bash
pnpm --filter @msw-tutorial/react-example dev       # Mock 模式
pnpm --filter @msw-tutorial/react-example dev:real  # 真实后端模式
1
2

Vue 示例：

bash
pnpm --filter @msw-tutorial/vue-example dev        # Mock 模式
pnpm --filter @msw-tutorial/vue-example dev:real   # 真实后端模式
1
2

脚本本质是 Vite 的 --mode：

json
{
  "scripts": {
    "dev": "vite --mode mock",
    "dev:real": "vite --mode real",
    "build": "vite build --mode mock",
    "build:real": "vite build --mode real"
  }
}

后端就绪后，只需要把 VITE_API_BASE_URL 换成真实网关地址。部署平台（CI/CD、Docker、K8s ConfigMap）也可以直接注入同名环境变量，无需提交 .env.real 的最终值。

配置在启动时解析一次 ​

src/config.ts：

ts
import { resolveRuntimeConfig } from "@msw-tutorial/contract"

export const runtimeConfig = resolveRuntimeConfig(import.meta.env)
export const isMockMode = runtimeConfig.mode === "mock"
1
2
3
4

resolveRuntimeConfig() 会做三件事：

  1. 校验 VITE_API_MODE 只能是 mock | real；
  2. 校验 VITE_API_VERSION 在当前契约白名单内；
  3. 规范化 baseUrl（去末尾斜杠，补前导斜杠）。

非法配置会在启动时直接抛错，避免带着错误地址联调半天。

启动入口按模式分支 ​

ts
async function bootstrap() {
  if (isMockMode) {
    // 只有 Mock 模式才加载 MSW；Real 模式不会把 worker 打进首屏
    const { startMockWorker } = await import("@msw-tutorial/mocks/browser")
    await startMockWorker()
  }

  createRoot(document.getElementById("root")!).render(<App />)
}

注意两点：

  • 必须等 startMockWorker() 完成再渲染，否则首屏请求可能绕过拦截。
  • Real 模式使用动态 import()，生产包里不会预加载 MSW。

真实后端接入检查表 ​

  • [ ] VITE_API_MODE=real
  • [ ] VITE_API_BASE_URL 指向真实网关（含 /api 前缀）
  • [ ] 后端支持 X-Api-Version 协商，并回写 X-Request-Id
  • [ ] 后端错误体符合统一错误信封
  • [ ] 后端接受 Authorization: Bearer <accessToken>
  • [ ] 写接口支持 Idempotency-Key（至少不报错）
  • [ ] 跨域场景下后端放行 X-Request-Id、X-Api-Version、Idempotency-Key 请求头
  • [ ] 登录/Cookie 场景确认 credentials 策略（本项目使用 Bearer，不依赖 Cookie）

同域代理方案（可选） ​

如果真实后端和前端不同域，且不想处理 CORS，可以继续让浏览器请求 /api，由 Vite dev server 代理：

ts
// vite.config.ts
export default defineConfig({
  server: {
    proxy: {
      "/api": {
        target: "https://api.example.com",
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, "/api"),
      },
    },
  },
})

回滚 ​

联调出现问题时，一条命令切回 Mock：

bash
pnpm --filter @msw-tutorial/react-example dev
1

无需回滚代码、无需改分支。Mock 数据来自固定 Faker 种子，问题可复现。
